<h1 align="center">Rezor</h1>

Rezor 是一个基于 React 的小程序框架，它是最快的 React 小程序框架，没有之一！你可以在不牺牲性能和用户体验的前提下，使用 React (Hooks) 开发小程序。

## 快速开始

```bash
npm create rezor@latest
```
